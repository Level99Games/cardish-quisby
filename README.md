# Prototype Card Maker

Card game prototyping from Level 99 Games: layouts, data sources, a card maker, and print-ready export
(Print & Play PDF, Tabletop Simulator sheets, preview images, and press PDFs with printer's marks).

## Download

Get the latest version from the **[Releases page](https://github.com/Level99Games/cardish-quisby/releases/latest)**.

- **Windows 10/11:** download `Prototype-Card-Maker-Setup-<version>.exe` and run it.
  If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
- **Mac (Apple chip, M1 or newer):** download `Prototype-Card-Maker-<version>-mac-arm64.dmg`, open it, and drag the app
  to Applications. The first time, right-click the app and choose **Open**, then confirm.

## Updates

Windows copies update themselves: new versions download in the background and the app shows
**Restart to update**. Mac copies show **Download** when a new version is out.

This repository only holds the installers. Your projects stay on your own computer.
